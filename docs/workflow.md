# 制作手順

この文書はユーザーの希望と本プロジェクトでの応用を記録するもの。有料講座本文そのものの代替ではない。講座：AIで「ドラマ」を撮る｜累計450万回再生『網戸一枚』は、こう作りました（https://note.com/junjun_ranran/n/nd85a8fcd6b2a）。

## 各作業前
1. 最新の依頼と許可範囲を読む。
2. 該当する講座本文を毎回実際に再読する。章節と出典、未読・アクセス不可の箇所を記録する。要約や記憶で代用しない。
3. 今回の動画の実フレームで位置・向き・姿勢・接地・小道具・始終状態を照合。音声は直接聴き、語尾と編集点を確認する。
4. 本文に書かれた内容と今回への応用を区別して、見せ場・画角・編集点・参照役割を決める。必要な動作を固定秒数に押し込んで省かない。細かな芝居は場面の気持ちに任せる。
5. 実行許可がある場合だけ、実設定と参照追加後の表示価格を確認して送信へ進む。準備依頼を生成許可と解釈しない。

## 生成後
元データを保存し、始終状態・台詞と話者・左右・接触・編集点を実再生で検品。その後に気持ち・反応・間が場面として成立するか判断。数値検査だけで視聴済みとしない。使える区間と未達を分け、結果を見てから次の指示を書く。未達を理由に無断で再生成しない。

## 記録
STATUS.mdを最新にし、素材のパス・ハッシュ・Library ID、価格の設定条件、成功／失敗／未確認を残す。設計変更後は一次情報・古くなった文書・実行前提を確認する。
